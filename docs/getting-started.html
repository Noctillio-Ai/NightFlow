Install NightFlow

NightFlow runs on macOS (Apple silicon) and Linux, with Windows 11 support in beta. Install it with a single command, or use Homebrew on macOS.

PlatformArchitecturePackage
macOSApple siliconDMG
Linuxx64Debian package / AppImage
Windows 11 (beta)x64Installer (.exe)

Install with one command (macOS & Linux)

The quickest path. This script downloads the right release for your OS and architecture, verifies its checksum, and installs it. On macOS it also clears the Gatekeeper quarantine flag on the app bundle; on Linux it installs the AppImage into ~/.local/bin with a desktop entry.

curl -fsSL https://raw.githubusercontent.com/Noctillio-Ai/NightFlow/main/install.sh | bash

Linux: prefer the Debian package? Append -s -- --deb. Install a specific version with -s -- --version X.Y.Z.

Install on Windows 11 (beta)

Run this in PowerShell. The script downloads the latest Windows installer, verifies its checksum, and installs NightFlow.

irm https://raw.githubusercontent.com/Noctillio-Ai/NightFlow/main/install.ps1 | iex
Windows support is in beta.

It needs Windows 11 (build 22000 or later) on an x64 PC; the installer won’t run on Windows 10 or earlier. The installer isn’t code-signed yet, so SmartScreen may warn about it. Please report anything that breaks.

Install with Homebrew on macOS

The project also maintains a Homebrew cask. The cask requires macOS Ventura or later.

brew tap noctillio-ai/nightflow https://github.com/Noctillio-Ai/NightFlow.git
brew install --cask nightflow

Updating NightFlow

NightFlow checks GitHub for new releases and can update itself. When an update is available, click Update: the app downloads the matching release, closes, installs the new version, and relaunches automatically. Because updating quits the app, NightFlow asks first if a training run is active. If the update can’t run, the badge switches to Download and opens the release page instead. You can also re-run the one-command installer above at any time to move to the latest release.

Update a Homebrew installation

brew update
brew upgrade --cask nightflow

Prepare your machine

Use a supported macOS, Linux or Windows 11 machine with enough memory and disk space for your dataset, environment, and checkpoints. A GPU is optional.

BackendWhat you need
CUDAAn NVIDIA GPU, compatible driver, and CUDA-enabled PyTorch.
Metal / MPSA supported Mac and PyTorch environment with MPS available.
CPUA compatible PyTorch installation on Intel, AMD, or Apple silicon.

Dataset paths must be accessible from the machine running the training process. Dependencies and pretrained model weights may need to be downloaded before an offline workflow is possible.

Create your first project

Create a local project

Open NightFlow and choose a local connection. Name your project and select a writable project directory for configuration and run output.

Choose your task and model category

Select classification, multi-label classification, detection, or segmentation. Choose a model category suited to your compute budget; start small while checking the workflow.

Connect your dataset

Set the dataset format, class count, and data paths. For CSV, enter the image-path and label-column headers, plus an image root if paths are relative. Review the project summary.

Check the environment

Use the dashboard to synchronize your project, then expand the readiness checks in the workspace banner to see dataset validation and Python environment status. The training environment needs AutoTimm and the corresponding PyTorch dependencies. Initial setup can require network access.

Train, then inspect

Start training after resolving validation errors. Follow progress, inspect evaluation metrics, and return to Experiments to compare runs. Use a small dataset for the first end-to-end check.

A small dataset to begin with

For image classification, arrange your images by split and class. Keep test images separate from training images so evaluation measures performance on unseen examples.

dataset/
  train/
    cat/
      image_001.jpg
    dog/
      image_002.jpg
  val/
    cat/
    dog/
  test/
    cat/
    dog/

Each class directory should contain the images for that class. Choose Folder format and point NightFlow to dataset/. Prefer CSV? See column mapping and examples.

Build from source

Developing NightFlow requires Node.js 22+, Rust stable with the 2024 edition, and the Tauri platform prerequisites. On macOS, install Xcode Command Line Tools. On Windows 11 (beta), install the Microsoft C++ Build Tools; WebView2 ships with Windows 11. On Debian/Ubuntu, install the system libraries below.

sudo apt-get update
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev \
  librsvg2-dev patchelf libgtk-3-dev libsoup-3.0-dev \
  libjavascriptcoregtk-4.1-dev
git clone https://github.com/Noctillio-Ai/NightFlow.git
cd NightFlow
npm install --legacy-peer-deps
npx tauri dev

For production builds use npx tauri build. See the contribution guide for validation commands and project structure.
